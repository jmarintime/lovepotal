# 🐻 푸푸 ♥ 지유 🐰 오늘부터 1일! 커플 탄생 축하 선물 앱

든든한 곰돌이 **푸푸**님과 러블리한 토끼 **지유**님의 설레는 **1일차**를 축하하기 위해 제작된 인터랙티브 웹 선물 포털입니다.

## ✨ 주요 기능 및 이펙트
1. **🎁 오프닝 선물 상자 언박싱**: 선물 상자를 터치하면 하트/별 컨페티 폭죽(`canvas-confetti`)과 팡파레 효과음이 터지며 포털이 열립니다.
2. **🌸 배경 벚꽃잎 & 터치 하트 버스트**: 화면 어디를 터치하든 귀여운 이모지(`💖`, `🐻`, `🐰`, `🌸`)가 톡톡 튀어 오릅니다.
3. **🔥 푸푸❤️지유 러브 온도계 & 축복 탭 게임**: 커스텀 제작된 곰돌이&토끼 일러스트와 함께 하트를 연타해 온도를 **100°C**까지 올리면 스페셜 폭죽과 말풍선이 변경됩니다.
4. **⏱️ 실시간 D+1 사랑 시계 & 기념일 타임라인**: 1초 단위로 올라가는 실시간 사랑 타이머와 **22일(투투데이), 50일, 100일, 200일, 300일, 1주년** 날짜가 자동 계산됩니다. (화면에서 1일 시작 날짜 변경 가능)
5. **📜 제1호 연애 계약서 & 커플 임명장**: 푸푸(갑)와 지유(을)가 각각 화면의 도장란을 터치하면 화면 흔들림 이펙트와 함께 빨간 인장(`푸푸之印`, `지유之印`)이 찍히며 공식 커플 임명장이 완성됩니다.
6. **🎟️ 사랑의 소원 쿠폰북**: 안아주기권, 삐짐 즉시 해제권, 맛집 풀코스 쏘기권 등 터치해서 사용 완료 스탬프를 찍을 수 있고, 나만의 커스텀 쿠폰도 즉시 발행할 수 있습니다.
7. **🎰 데이트 코스 뽑기 룰렛 & ⚖️ 커플 텔레파시 밸런스 게임**: 오늘/주말 데이트 코스와 비밀 미션을 뽑거나, 푸푸와 지유가 차례대로 골라 텔레파시 일치율을 확인할 수 있습니다.
8. **📸 1일차 폴라로이드 액자 & 커플 버킷리스트**: 휴대폰 갤러리에서 두 사람의 사진을 골라 폴라로이드 액자에 끼워 넣을 수 있습니다.
9. **💌 씰링 왁스 축하 편지 & 롤링페이퍼 (+ 카톡 공유 링크 복사)**: 봉투의 왁스 씰을 뜯어 친구의 편지를 읽을 수 있으며, 편지 내용을 수정한 뒤 **`카톡 공유 링크 복사`** 버튼을 누르면 URL 파라미터에 편지와 날짜가 담겨 카카오톡으로 그대로 선물할 수 있습니다.
10. **🎵 내장 오르골 BGM & 효과음 신디사이저**: 외부 음원 파일 깨짐 없이 Web Audio API로 구현된 로맨틱 오르골 멜로디와 효과음을 상단 바에서 언제든 켜고 끌 수 있습니다.

## 🚀 로컬 실행 및 Vercel 배포 방법

```bash
# 개발 서버 실행
npm run dev

# 프로덕션 빌드 테스트
npm run build
npm run start
```

### Vercel에 올리기
1. GitHub 레포지토리에 푸시한 뒤 [Vercel](https://vercel.com)에서 **Add New Project**로 불러오거나,
2. 터미널에서 `npx vercel --prod` 명령어를 실행하면 즉시 배포됩니다.
